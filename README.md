## Etap 1 – Podstawy Kotlin

W ramach pierwszego etapu wykonałem:
- Program wyświetlający dane ucznia z użyciem `val` i `var`.
- Funkcję obliczającą liczbę godzin zajęć.

## Uruchomienie

1. Otwórz https://play.kotlinlang.org/
2. Wklej kod z pliku `uczen.kt` lub `godziny.kt`.
3. Kliknij **Run**.
